# 📐 OpenSCAD Projects: Learning Repository

Este repositorio contiene una colección de proyectos modelados con [OpenSCAD](https://openscad.org/), como parte de un aprendizaje práctico para diseñar organizadores y estructuras relacionadas con tecnología (microSD, RAM, componentes electrónicos, etc).

## 🌿 Rama: `learn`

Todos los proyectos en esta rama están estructurados en carpetas independientes, cada una con su propio `README.md` y archivos `.scad`.

---

## 📁 Estructura del Proyecto


prj-openscad/

├── README.md           <-- Este archivo

├── cubo/               <-- Proyecto de ejemplo

│   ├── cube.scad

│   └── README.md

## 🛠️ Requisitos

- [OpenSCAD](https://openscad.org/)
- Editor de texto o IDE (por ejemplo, VS Code con extensión de OpenSCAD)
- Git

---

## 🚀 Cómo iniciar

```bash
git clone -b learn https://github.com/tuusuario/prj-openscad.git
cd prj-openscad/cubo
openscad cube.scad
```
